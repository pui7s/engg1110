# 桃花源耕讀

一個水墨風的種田小遊戲。你是個一無所有的農夫，誤入陶淵明筆下的桃花源，從一把借來的舊鋤和一包蘿蔔籽開始，開荒、種菜、蓋房子，一步步過上自己想要的生活。

直接用瀏覽器打開 `index.html` 就能玩，不需要安裝或編譯。存檔自動留在瀏覽器裏。

## 怎麼玩

- **點田地**：開墾、播種、澆水、除草、捉蟲、施肥、收成。做過一次的活，可以接着點別的田連續做。
- **歇息**：力氣用完就歇息，時間前進一候（五天）。三候為一節氣，二十四節氣為一年。
- **觀天**：每候看一個天象（燕子低飛、朝霞、月暈……），猜下一候的天氣。猜過之後，那條農諺和它背後的道理就記進農書。
- **請教**：每個節氣向田翁請教一次，聽他講這個節氣的農事，再答一道題。
- **市集／營造**：收成換錢、買種子；攢木石蓋茅屋、水井、雞舍、水車、書齋、桃花亭。
- **農書**：作物的播種時令表、走過的節氣、學到的農諺，還有七個心願。

## 會學到什麼

- 二十四節氣與七十二候，以及每個節氣該做的農事
- 九種晉代已有的作物（蘿蔔、韭菜、白菜、大豆、胡瓜、茄子、粟、小麥、水稻）各自的時令與習性
- 輪作、豆類固氮、冬小麥春化、霜打菜更甜、瑞雪兆豐年這些道理
- 二十五條看天的農諺，和它們的氣象解釋
